# LanBeam — план реализации

## Цель
Русскоязычное веб-приложение для передачи файлов между телефоном и ПК в одной Wi‑Fi сети. Пользователь открывает один адрес на ПК и телефоне; файлы проходят через локальный Express-сервер проекта и не требуют регистрации или облачного хранилища.

## Подход к реализации
- Express добавляет HTTP API `/api/lan/status`, `/api/lan/files`, `/api/lan/upload` и `/api/lan/files/:id/download`.
- Загруженные файлы записываются в локальную директорию `.lanbeam-data/files`, а метаданные — в JSON-индекс этой же директории.
- Браузер отправляет файл через `XMLHttpRequest`, чтобы показывать реальный процент загрузки; скачивание выполняется обычной ссылкой на download endpoint.
- React-интерфейс остаётся одинаковым для телефона и ПК: выбор нескольких файлов, очередь передачи, состояние сервера, история и повторное скачивание.
- Вся работа идёт в рамках одного origin, поэтому на локальной сети не нужны отдельные CORS-настройки, аккаунты или внешние сервисы.

## Дизайн

### Варианты направления
- **Технический янтарь — 0.07:** тёмная рабочая поверхность, янтарные акценты, ощущение надёжного сетевого инструмента.
- **Морской стек — 0.05:** бело-синяя карточная панель с холодной, лёгкой утилитарной эстетикой.
- **Бумажный конверт — 0.03:** светлый фон, мягкие серо-зелёные акценты, метафора передачи через конверт.

Выбран **технический янтарь**.

- **Design Movement:** dark utility / terminal-inspired interface with restrained industrial details.
- **Core Principles:** мгновенно понятный статус; один главный сценарий на экран; высокий контраст и крупные touch-targets; информация о файле всегда рядом с действием.
- **Color Philosophy:** графитовый фон снижает визуальный шум, янтарный служит собственным цветом LanBeam и отмечает активные действия, зелёный используется только для подтверждённой готовности, красный — только для ошибок.
- **Layout Paradigm:** асимметричная рабочая панель: слева контекст и адрес подключения, справа широкая зона передачи; на мобильном контекст превращается в компактную верхнюю ленту.
- **Signature Elements:** янтарная вертикальная линия у бренда; пунктирная drop-zone рамка; маленькие сетевые метки `LOCAL / READY`.
- **Interaction Philosophy:** любое действие отвечает сразу: кнопка меняет состояние, загрузка показывает проценты, завершённый файл появляется в истории без перезагрузки.
- **Animation:** короткие 160–220 мс переходы, мягкое свечение только у активной зоны и progress bar; без непрерывных декоративных анимаций.
- **Typography System:** `Manrope` для интерфейса и `IBM Plex Mono` для адреса, меток и технических значений; заголовок 40–52 px на десктопе и 30–34 px на мобильном.
- **Brand Essence:** «Файлы рядом, когда нужно» — практичный, спокойный, быстрый.
- **Brand Voice:** коротко и по делу. Примеры: «Откройте этот адрес на телефоне» и «Файл уже на компьютере».
- **Wordmark & Logo:** слово `lanbeam` в плотном гротеске с янтарной точкой-лучом между `lan` и `beam`; в UI используется как текстовый знак с отдельным светящимся маркером.
- **Signature Brand Color:** янтарный `#F6B84B`.

## Структура проекта
- `server/_core/index.ts` — Express middleware и подключение LAN API.
- `server/lanFiles.ts` — локальное хранилище, метаданные, потоковая загрузка и скачивание.
- `client/src/pages/Home.tsx` — основной экран и клиентские сценарии.
- `client/src/index.css` — визуальная система LanBeam и адаптивные правила.
- `client/public/manus-routes.json` — манифест страницы.

## Ограничения
В этой версии файлы хранятся на диске процесса и доступны всем, кто имеет доступ к адресу в локальной сети. Для домашней сети это удобно; перед передачей чувствительных файлов пользователь должен убедиться, что сеть доверенная. Серверный список и история рассчитаны на текущий экземпляр приложения и не требуют базы данных.
